# Viyam 1.0.2

Released 25 November 2026.

- **Automatic inbox check** can recover missed messages from approved bank senders once Android makes them readable. In **Settings > Bank SMS**, choose 15 minutes, 30 minutes or 1 hour. The setting starts off, and Android may delay background checks.
- Viyam skips saved messages, including ignored ones. New unrecognized alerts appear in **Needs review** and stay outside financial totals. Review notifications use a generic message.
- The first check covers up to 24 hours within the tracking period. Use **Import history** for older messages.

## Installation

Install **Viyam-1.0.2.apk** over the existing public release. The app uses the same application ID and signing certificate, with version code 4. The upgrade from 1.0.1 was verified on Android 10 with a saved sample ledger. Requires Android 7.0 or later. If Android reports a signing conflict, keep the existing installation and see the [installation guide](https://github.com/atheeqrc/Viyam-Releases/blob/v1.0.2/docs/INSTALLATION.md).
